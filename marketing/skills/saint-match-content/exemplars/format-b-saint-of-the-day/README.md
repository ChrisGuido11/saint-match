# exemplars/format-b-saint-of-the-day/ — Format B specimens

**Format B is the saint-of-the-day post, and it is the standard for daily
posts.** It is a distinct format from the themed long-form posts in the parent
`exemplars/` directory — not a shortened version of them.

| File | What it is | Words | Hinge |
| --- | --- | --- | --- |
| `01-REFERENCE-ewtn-st-clare.md` | **Third-party.** EWTN Instagram caption. Style study only. | ~55 | *broadcast* |
| `02-st-raymond-nonnatus.md` | Saint Match specimen, drafted in-house, not yet shipped. | ~38 | *what can't be put into words* |

## The format in one table

| | Format A (`exemplars/`) | **Format B (here)** |
| --- | --- | --- |
| Body | 200–500 words | **~40–70 words** |
| Person | Sustained second person | **Third person** |
| Facts | Many, woven | **One, doing all the work** |
| Bridge | Stated internally, felt in the body | **Performed as a hinge** |
| Ending | Scripture → ✝️ → engagement → app mentions → hashtags | **"St [Name], pray for us."** |
| CTA | Engagement line + app-mention pair | **The hinge is the CTA. No pitch.** |
| Emoji | ✝️ and 🙏🔥 required | **None** |
| Hashtags | 15–20 niche + 3–5 buried trending | **None** |
| Floor checks | V1–V7 (`SCORER.md` §3A) | **W1–W5 (`SCORER.md` §3B)** |

**The absence of Format A's furniture is correct, not a defect.** A scorer that
STOPs a Format B post for having no scripture block is making exactly the
mistake this whole realignment was written to fix, pointed the other way.

## The hinge

A single word or concept from the saint's life is **carried over** into what
Saint Match does. Saint Match's hinge is the app's actual function: *the saint
carried a specific thing, and the app matches a person to the saint who carried
theirs.*

The rule that makes it work: **perform it, never state it.** "Just like Saint
Match helps you find…" is the failure. The reader completes the connection, and
that completion is the whole effect. If a grader cannot name the hinge word in
one word or one short phrase, there is no hinge — see `SCORER.md` W2, where
inability to name it is itself the STOP.

## Truth discipline is unchanged

T1–T6 and I1–I4 apply to Format B exactly as they do to Format A, unweakened.
Shorter is not looser. The one addition is **W5**: Format B rests on exactly
**one** fact, and that fact may not be a LEGEND even when attributed — at 40–70
words an attributed legend is still the load-bearing claim.

## This set is thin

**Two specimens, one of them third-party and one of them unshipped.** That is
enough to fix the *shape*, which is why W1–W5 are binary and confident. It is
**not enough to rank on**: a forced ranking against two referents has almost no
resolution, and an odd-one-out test against a set of two is close to
meaningless.

So per `SCORER.md` §9.5, Format B voice scoring runs in **`shape-only` mode** —
qualitative notes yes, a usable `voice_score` no — and **Format B voice scores
must not accept or reject any rulebook edit** until the set reaches **at least
four or five Saint Match specimens**.

**The user has been asked for more.** When they arrive, adding them is a
deliberate re-baselining event: record it, and treat scores from before and
after as belonging to different scales. Ideally the additions are *shipped* Saint
Match posts, which would also let the EWTN reference be demoted to background
reading rather than counted as a referent at all.

## Rules for this folder

- **Never score a Format B post against the Format A exemplars, or the reverse.**
  A cross-format comparison measures the format difference and nothing else, and
  it produces confident, plausible, wrong reasons. `SCORER.md` §9.1.
- The EWTN caption is **reference, not gold**. It fixes the mechanic. It is not
  Saint Match's voice and it is not under Saint Match's sourcing discipline.
- Do not edit the specimens to taste. A referent that moves cannot measure
  change.
